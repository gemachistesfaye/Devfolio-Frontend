# Devfolio-Frontend 🎨

Modern, SaaS-style full-stack developer portfolio built with React, TypeScript, and Vite. Designed for recruiters and potential clients.

## 🌟 Key Features
- **Developer Mode**: Systems and architecture focus.
- **Client Mode**: Business ROI and services focus.
- **AI Assistant**: Interactive widget for project-specific queries.
- **PWA Support**: Installable as a native app on mobile/desktop.
- **Glassmorphism UI**: Premium dark-mode aesthetic with purple accents.

## 🛠 Tech Stack
- **React 18**: Frontend library.
- **TypeScript**: Static typing.
- **Vite**: Ultra-fast build tool.
- **Tailwind CSS**: Utility-first styling.
- **Framer Motion**: Smooth animations and transitions.
- **Lucide React**: Clean iconography.

## 📂 Structure
```text
src/
├── pages/         # Mode-specific views
├── components/    # Reusable UI elements
├── services/      # API communication layer
└── styles/        # Global design system
```

## 🚀 Deployment
- **Platform**: Vercel / Netlify.
- **Build Command**: `npm run build`
- **Output Directory**: `dist`

## ⚙️ Environment Variables
```env
VITE_API_URL=https://your-api-url.com/api
```
